# Sheet Nest — розкрій листових матеріалів

Веб-застосунок для 2D оптимізації розкрою МДФ, фанери, ДСП тощо.

## Можливості MVP

- **Матеріали** — CRUD з збереженням у `localStorage` (назва, тип, товщина, розмір листа, малюнок, кількість)
- **Деталі** — таблиця + вставка з Excel/Sheets з попереднім переглядом; одиниці мм/см/м
- **Налаштування** — пропил (kerf), поворот 90°, малюнок, режими MaxRects / Guillotine
- **Алгоритм** — реальний 2D bin packing у модулі `src/nesting/` (без React)
- **Карта** — SVG-схема з номерами, розмірами, pan/zoom
- **Статистика** — листи, площі, % використання, нерозміщені деталі

## Запуск

```bash
npm install
npm run dev
```

Відкрийте [http://127.0.0.1:4637](http://127.0.0.1:4637).

## Скрипти

| Команда        | Опис                |
|----------------|---------------------|
| `npm run dev`  | Dev-сервер (порт 4637) |
| `npm run build`| Production build    |
| `npm run test` | Unit-тести nesting  |
| `npm run preview` | Preview build    |

## Структура

```
src/nesting/     # алгоритми MaxRects / Guillotine (чистий TS)
src/components/  # UI панелі та SVG-карта
src/lib/         # localStorage, парсер буфера
```
